📖 1. 專案簡介 (Project Overview)
《舊驛新憶》是一份針對 18–30 歲 Z 世代風格探索者、外地觀光客與過境通勤轉運族打造的鐵道文化微觀光專案。專案以「臺中驛鐵道文化園區」（國定古蹟二代車站、舊軌道月台、退役列車 EMU100／DR2700、三代高架站體與鐵鹿大街）為核心，透過奇幻時空穿越短影音、網頁視覺體驗與行銷企劃，解決通勤人流過境化與動線指引模糊的痛點，將歷史古蹟轉化為具備社群擴散力與生活溫度的故事場域。

🎨 2. Vibe 視覺與設計語彙 (Design Tokens & Vibe)

設計元素	Token / 代碼	說明與意象
主背景 (Primary BG)	#121316	炭焙深鐵黑 (Charcoal Dark)，如夜間鐵道月台般的電影底色
卡片背景 (Card BG)	#1A1C23 / #242833	沉穩鋼鐵深灰，營造清晰而內斂的分層視覺
古蹟紅磚主色 (Brand Brick)	#B33927	百年國定古蹟辰野式紅磚外觀，象徵歷史傳承與溫度
軌道金重點色 (Rail Gold)	#C59B27	復古銅鐘、金色晨光與時空車票的光澤點綴
羊皮紙米白 (Parchment White)	#F4ECE1	復古車票與老明信片紙質色澤，柔和護眼
鋼軌灰輔助 (Steel Gray)	#8E9AAF	象徵退役列車金屬與現代鋼構站體的科技平衡
主字體 (Typography)	Noto Serif TC	襯線宋體/明體，呈現古蹟文史與經典名片的厚重人文質感
副字體 (Sans-Serif)	Inter / Noto Sans TC	簡潔現代無襯線體，適合 Meta 資訊、數據與按鈕標籤

你是一位精通「復古鐵道人文美學」與「電影敘事質感」的高級前端工程師與觀光行銷設計師。

[設計語言規範 (Design System)]
1. 視覺風格：百年鐵道復古電影風 (Railway Cinematic Heritage)，嚴禁冷白單調色塊或粗糙高彩度漸層。
2. 色彩代碼：
  - Primary BG: #121316 (炭焙黑)
  - Card BG: #1A1C23 / #242833 (鋼鐵深灰)
  - Main Brand: #B33927 (二代古蹟紅磚赤色)
  - Accent / Gold: #C59B27 (月台晨光 / 銅鐘金)
  - Text Ink: #F4ECE1 (羊皮紙米白) / #8E9AAF (鋼軌灰)
3. 排版細節：
  - 大標題與次標題統一使用 serif (Noto Serif TC)。
  - 核心組件支援復古打孔車票（Ticket Stub）、時空郵筒（Postcard Capsule）與分鏡表格樣式。
  - 按鈕採用金屬質感邊框與紅磚微光暈投影效果。

[技術要求]
1. HTML5 語意化標籤 + 獨立 style.css。
2. 完整 RWD 響應式斷點 (xs:475px, sm:640px, md:768px, lg:1024px)。
3. 嚴謹 SEO 結構化標籤 (Open Graph、Twitter Cards、Schema.org TouristAttraction JSON-LD)。
4. 所有景點與展覽地圖連結必須包含精確 Google Maps 坐標或 Place ID。
